# 2.0 demo：关系出处 + 搜索或提问

只在 `demo-2.0` 分支上，不合并进 `cleanup`。

预览：在仓库根目录运行 `python3 -m http.server 8000`，打开
`http://localhost:8000/#character-recall-character-winston-smith-1910e4339629`（温斯顿·史密斯词条）。

1. **关系**：温斯顿词条正文开头下面多了「关系」一节。17 条关系按故事顺序围成一圈（手机上是一列）。点人物或连线，下面列出这条关系的原文出处；点出处，滚到正文那一句并标黄。
2. **搜索或提问**：按 Ctrl K 或点「搜索」，空输入时顶部有 3 个示例问题；输入问句也会出现「提问」。回答先显示读了哪些词条，再逐字出现，每句带来源编号；下面画出回答用到的关系；点编号、来源或连线，跳到对应词条并标出那一句。

文件：`data.js`（关系标签、出处、预置回答，出处都逐字取自词条）、`relations.js`（关系图和标出原文）、`ask.js`（提问流程）、`demo2.css`。`app.js` 只改了搜索面板几行，用来加「提问」入口。
