# 2.0 demo：关系出处 + 助手问答

只在 `demo-2.0` 分支上，不合并进 `cleanup`。

预览：在仓库根目录运行 `python3 -m http.server 8000`，打开
`http://localhost:8000/#character-recall-character-winston-smith-1910e4339629`（温斯顿·史密斯词条）。

1. **关系**：不在正文里。展开图谱（桌面点小图谱右下角，手机点右下角图谱按钮），左上角可以在「图谱」和「关系」之间切换。关系模式下，17 条关系按故事顺序围成一圈（手机上是一列）；点人物或连线，列出这条关系的原文出处；点出处，收起图谱，滚到正文那一句并标黄。
2. **助手**：和搜索分开。右下角常驻「助手」按钮（参考 Craft），点开后右侧面板靠边停靠，正文自动让出位置；搜索框（Ctrl K）只做搜索。面板首次打开有 3 个示例问题，也可以直接输入。
   - 回答分层：一句结论，再分几段讲背景、经过、原因和主题；人物和地点第一次出现时带一句简介，每个说法带来源编号，编号按阅读顺序排。
   - 点编号或词条名，词条在面板里打开并标出那一句；左上角返回对话，右上角可以打开完整词条页。
   - 结论下面是这件事的关系图：人物和地点之间“谁对谁做了什么”，每条连线带来源编号；悬停引用编号时对应连线会亮起，点连线打开出处，点节点在面板里打开词条。
   - 「事件经过」按故事顺序列出回答用到的情节，「来源」列出全部原文出处，两者默认收起。
   - 回答末尾有追问建议，底部输入框可以继续问。

文件：`data.js`（关系标签、出处、预置回答，出处都逐字取自词条）、`relations.js`（关系图和标出原文）、`ask.js`（对话面板）、`demo2.css`。`app.js` 只向 `ReadipediaBridge` 暴露了 `articleModel`，让面板能渲染词条。
